# env

The `env` command retrieves the configured environment variables.


## Usage
```
./cx utils env [flags]
```


## Flags
**`---help, -h`**

Help for the env command.


## Examples
### Using the env command
```
uaer@laptop:~/ast-cli$ ./cx utils env

Detected Environment Variables:

            cx_proxy_auth_type:
                  cx_client_id:
              cx_client_secret:
                     cx_apikey:
                     cx_branch:
                    cx_timeout:
                   cx_base_uri:
                     cx_tenant:
                    http_proxy:
                  sca_resolver:
              cx_base_auth_uri:
```
