# help

The `help` command **provides a help menu** for **every CLI command/Sub-command** (Path for the command).


## Usage
```
./cx help [command] [flags]
```


## Available Commands
```
auth
configure
help
project
result
scan
utils
version
```


## Flags
**`--help, -h`**

Help for the help command.
